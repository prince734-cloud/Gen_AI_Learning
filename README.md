# Gen_AI_Learning
Exploring Generative AI fundamentals, RAG pipeline construction, and LLM orchestration using LangChain and Python.

Welcome to my Generative AI learning repository! This project serves as a central hub for hands-on experiments, tutorials, and applications built using **LangChain** and modern Large Language Model (LLM) tools.

## 📌 Topics Covered
- **LangChain Fundamentals:** Chains, Prompts, Output Parsers, and Memory
- **Retrieval-Augmented Generation (RAG):** Document loading, vector databases, and semantic search
- **Autonomous Agents & Tools:** LangGraph, custom tool integration, and multi-agent systems
- **LLM Integrations:** Working with OpenAI, Hugging Face,MistralAI, and local models (Ollama)

## 🛠️ Tech Stack
- **Language:** Python
- **Frameworks:** LangChain
- **Vector DBs:** ChromaDB / FAISS / Pinecone
